# Frontend Architecture Guideline

## Laravel 12 + Blade + TailwindCSS + Vite

Version: 1.0

---

# 1. Mục tiêu

Kiến trúc Frontend phải đảm bảo:

* Dễ đọc
* Dễ mở rộng
* Tái sử dụng Component
* Không lặp code
* Chuẩn MVC của Laravel
* Dễ chuyển sang React/Vue nếu sau này cần

Không viết HTML dài hàng nghìn dòng trong một file.

Mỗi file chỉ nên đảm nhiệm một nhiệm vụ.

---

# 3. Ý nghĩa từng thư mục

## layouts

Chứa khung chung của website.

Ví dụ

* Head
* Font
* Vite
* Navbar
* Footer

Không chứa nội dung của từng trang.

---

## pages

Mỗi file tương ứng một Route.

Ví dụ

```
/
```

↓

```
pages/home.blade.php
```

```
/products
```

↓

```
pages/product/index.blade.php
```

```
/products/macbook-air
```

↓

```
pages/product/show.blade.php
```

Page chỉ có nhiệm vụ ghép các Component.

Không nên chứa HTML phức tạp.

---

## components

Là nơi chứa toàn bộ UI.

Component có thể tái sử dụng.

Ví dụ

Product Card

sẽ được dùng ở

* Homepage
* Search
* Wishlist
* Related Product
* Category

Chỉ viết một lần.

---

## ui

Chứa Component nhỏ.

Ví dụ

Button

Input

Badge

Modal

Loading

Pagination

Toast

Skeleton

Những Component này không liên quan tới nghiệp vụ.

Có thể dùng ở mọi nơi.

---

## common

Những Component dùng chung.

Ví dụ

404

Loading

Empty Result

Error Message

# 7. Component Size

Một Component nên dưới khoảng

200 dòng.

Nếu vượt

300 dòng

nên tách nhỏ.

Ví dụ

```
Product Detail

↓

Gallery

↓

Information

↓

Specification

↓

Review

↓

Related Product
```

---

# 8. Controller

Controller chuẩn bị dữ liệu.

Ví dụ

```
HomeController
```

```
return view(...)
```

với

```
featuredProducts

latestProducts

categories
```

View không Query Database.

View chỉ hiển thị.

---

# 9. Blade Component

Ưu tiên

```
<x-product.card />
```

thay vì

```
@include(...)
```

Lý do

* Có Props
* Đẹp hơn
* Dễ bảo trì
* Gần giống React Component

Ví dụ

```
<x-product.card
    :product="$product"
/>
```

---

# 10. Quy tắc đặt tên

Tên file

```
hero.blade.php

featured-products.blade.php

latest-products.blade.php
```

Không dùng

```
Hero.blade.php

HeroComponent.blade.php
```

Tên thư mục

chữ thường

dùng dấu -

# 19. Khi nào tạo Component mới?

Badge
