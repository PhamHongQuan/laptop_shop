# Laptop Shop - Requirement

## 1. Project Overview

Xây dựng website bán laptop theo mô hình E-commerce.

Tech Stack

- Laravel 12
- PHP 8.4
- MySQL 8
- Docker
- Redis
- React
- TailwindCSS

- Quản lý Product
- Quản lý Product Image
- Quản lý Product Specification
- Quản lý User
- Quản lý Order

### Customer

- Register
- Login
- Logout
- Forgot Password
- Xem danh sách laptop
- Xem chi tiết laptop
- Tìm kiếm
- Lọc sản phẩm
- Thêm vào giỏ hàng

- Theo dõi đơn hàng
