# ERD - Laptop Shop (MVP v1.0)

## Database Information

Database: `laptop_shop`

Engine: InnoDB

Charset: utf8mb4

Collation: utf8mb4_unicode_ci

---

# Design Philosophy

Đây là phiên bản **MVP (Minimum Viable Product)**.

Mục tiêu:

* Database đơn giản.
* Dễ học Laravel.
* Dễ CRUD.
* Dễ mở rộng về sau.

Các bảng như:

* brands
* product_specs
* coupons
* reviews
* wishlist
* payments

sẽ được bổ sung ở các phase sau.

# Tables

| Table          |
| -------------- |
| users          |
| categories     |
| products       |
| product_images |
| carts          |

---

# users

| Column     | Type         | Description        |
| ---------- | ------------ | ------------------ |
| id         | BIGINT       | Primary Key        |
| name       | VARCHAR(100) | Full Name          |
| email      | VARCHAR(100) | Unique Email       |
| password   | VARCHAR(255) | Password Hash      |
| phone      | VARCHAR(20)  | Phone              |
| role       | TINYINT      | 0=Customer,1=Admin |
| created_at | TIMESTAMP    | Created Time       |
| updated_at | TIMESTAMP    | Updated Time       |

Indexes

* PK(id)
* UNIQUE(email)

---

# categories

| Column     | Type         | Description   |
| ---------- | ------------ | ------------- |
| id         | BIGINT       | Primary Key   |
| name       | VARCHAR(100) | Category Name |
| slug       | VARCHAR(120) | URL Slug      |
| created_at | TIMESTAMP    | Created Time  |
| updated_at | TIMESTAMP    | Updated Time  |

Indexes

* PK(id)
* UNIQUE(slug)

---

# products

Thông số laptop được lưu trực tiếp trong bảng để đơn giản hóa hệ thống.

| Column      | Type          | Description   |
| ----------- | ------------- | ------------- |
| id          | BIGINT        | Primary Key   |
| category_id | BIGINT        | Category ID   |
| name        | VARCHAR(255)  | Product Name  |
| slug        | VARCHAR(255)  | URL Slug      |
| thumbnail   | VARCHAR(255)  | Thumbnail     |
| description | TEXT          | Description   |
| price       | DECIMAL(15,2) | Selling Price |
| stock       | INT           | Inventory     |
| cpu         | VARCHAR(100)  | CPU           |
| gpu         | VARCHAR(100)  | GPU           |
| ram         | VARCHAR(50)   | RAM           |
| storage     | VARCHAR(50)   | SSD/HDD       |
| screen      | VARCHAR(100)  | Screen        |
| created_at  | TIMESTAMP     | Created       |
| updated_at  | TIMESTAMP     | Updated       |

Indexes

* PK(id)
* INDEX(category_id)
* UNIQUE(slug)

---

# product_images

Một sản phẩm có nhiều hình ảnh.

| Column     | Type         | Description |
| ---------- | ------------ | ----------- |
| id         | BIGINT       | Primary Key |
| product_id | BIGINT       | Product ID  |
| image      | VARCHAR(255) | Image URL   |
| created_at | TIMESTAMP    | Created     |

Indexes

* PK(id)
* INDEX(product_id)

---

# carts

Mỗi dòng đại diện cho một sản phẩm trong giỏ hàng.

| Column     | Type      | Description |
| ---------- | --------- | ----------- |
| id         | BIGINT    | Primary Key |
| user_id    | BIGINT    | User        |
| product_id | BIGINT    | Product     |
| quantity   | INT       | Quantity    |
| created_at | TIMESTAMP | Created     |

Indexes

* PK(id)
* INDEX(user_id)
* INDEX(product_id)

---

# orders

| Column           | Type          | Description  |
| ---------------- | ------------- | ------------ |
| id               | BIGINT        | Primary Key  |
| user_id          | BIGINT        | User         |
| receiver_name    | VARCHAR(100)  | Receiver     |
| receiver_phone   | VARCHAR(20)   | Phone        |
| receiver_address | VARCHAR(255)  | Address      |
| total_price      | DECIMAL(15,2) | Total        |
| status           | TINYINT       | Order Status |
| created_at       | TIMESTAMP     | Created      |
| updated_at       | TIMESTAMP     | Updated      |

Status

* 0 = Pending
* 1 = Confirmed
* 2 = Shipping
* 3 = Completed
* 4 = Cancelled

Indexes

* PK(id)
* INDEX(user_id)

---

# order_items

Lưu snapshot của sản phẩm tại thời điểm đặt hàng.

| Column     | Type          | Description   |
| ---------- | ------------- | ------------- |
| id         | BIGINT        | Primary Key   |
| order_id   | BIGINT        | Order ID      |
| product_id | BIGINT        | Product ID    |
| price      | DECIMAL(15,2) | Product Price |
| quantity   | INT           | Quantity      |

Indexes

* PK(id)
* INDEX(order_id)
* INDEX(product_id)

---

# Logical Relationships

```
users

 └── orders
       └── order_items

      └── products
              └── product_images
```

# Notes

* Không sử dụng Foreign Key Constraint.
* Quan hệ giữa các bảng được xử lý bởi Laravel (Eloquent ORM).
* Thiết kế ưu tiên đơn giản để học và phát triển nhanh.
* Sau khi hoàn thành MVP mới tiếp tục chuẩn hóa database ở các phase tiếp theo.
